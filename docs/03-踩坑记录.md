# 踩坑记录

都是实测踩出来的，改启动器之前建议先扫一遍。格式：**症状 → 根因 → 解决**。

## 坑 1 · 桌面版报「应用程序的并行配置不正确」（SxS，最隐蔽）

- **症状**：双击启动器没窗口，事件日志里是"激活上下文生成失败，找不到从属程序集"。
- **根因**：**Windows 拒绝从 `%LOCALAPPDATA%`（AppData）目录加载 SxS 程序集**。
  程序缓存原本放在 `%LOCALAPPDATA%\CodexPortable\`，于是 exe 连同它的 `.manifest`
  被判为不可加载。同一份文件放 `E:\` 或 `D:\` 都正常，放 AppData 就挂。
- **解决**：缓存目录改成用户目录下的 `C:\Users\<用户名>\CodexPortable\<U盘ID>\`。

## 坑 2 · 桌面版与本机已装的 Codex 单实例冲突

- **症状**：双击后进程一闪就退，没有窗口。
- **根因**：U 盘版和本机安装版共用 `%APPDATA%\Codex`，Electron 的单实例锁把新进程合并掉了。
- **解决**：启动器把 `APPDATA` / `LOCALAPPDATA` 重定向到缓存目录下的独立路径。
- **别用** `--user-data-dir`：App 内部会再改 userData，结果窗口不显示。

## 坑 3 · 交互界面报「package does not match this platform」

- **症状**：`codex --version`、`codex exec` 都正常，唯独交互 TUI 报错退出。
- **根因**：主程序是按官方包里的原始长名（`codex-x86_64-pc-windows-msvc.exe`）存放的，
  而交互模式**要求可执行文件叫 `codex.exe`**。
- **解决**：重命名为 `codex.exe`（自动装配脚本里也做了这一步）。

## 坑 4 · 交互界面报「this CLI has no complete local package」

- **症状**：改名之后，TUI 又报没有完整的本地包。
- **解决**：**无参数启动 TUI 时**追加 `--no-daemon`。
  ⚠️ `exec` / `app-server` 等子命令**不能**加这个参数（会报 unexpected argument），
  所以启动器里的逻辑是"只有 `$args.Count -eq 0` 时才追加"。

## 坑 5 · 双击后窗口一闪就没 / 中文报语法错

- **根因**：`.ps1` 用 UTF-8 **无 BOM** 保存，而双击走的是系统自带的
  Windows PowerShell 5.1，它按 ANSI(GBK) 读文件 → 中文变成乱码 → 语法错误。
- **解决**：
  - `.ps1` 一律存成 **UTF-8 with BOM**；
  - `.cmd` 用 ANSI/GBK（或者干脆让 .cmd 内容全 ASCII，中文输出交给 .ps1）；
  - `.cmd` 里加 `if errorlevel 1 (echo ... & pause)`，避免出错时窗口直接关闭。

## 坑 6 · 密钥分片算法不匹配导致 401

- **症状**：`Your api key is invalid`（401），但拿同一把 key 直接 curl 服务商接口是 200。
- **根因**：生成时是"整体 XOR → 整体 Base64 → 切 3 段"，还原时却是"逐段 Base64 解码"，
  段边界不是 4 的倍数 → 解出错误字节。
- **解决**：统一成"**按字节切 3 段 → 每段独立 XOR（都从下标 0 起）→ 各自 Base64**"。
  仓库里的 `tools/mkshards.py` 和 `CodexHome/set-api-key.ps1` 都是这个算法，并且自带还原自校验。

## 坑 7 · 文件系统选择（FAT32 / exFAT / NTFS 都试过）

- **FAT32**：单目录最多约 1.6 万个长文件名项，程序包（一万九千多个文件）写到一半就报
  "无法创建目录或文件"。
- **NTFS**：在入门 U 盘上顺序写只有 2.7 MB/s（日志开销大）。
- **exFAT**：最终选择 —— 无目录项限制、跨平台可读写、顺序写最快。

## 坑 8 · U 盘测速"越写越慢"的误判

- **症状**：一开始测到 129 文件/秒，写了几百 MB 之后掉到 1.6 文件/秒，差点以为盘坏了。
- **真相**：那次测速时**另一个后台 robocopy 还在写同一个盘**（之前被中断的命令没结束）。
  排除干扰后复测，稳定在 30 文件/秒左右。
- **教训**：测速和大量写入之前，先确认没有残留的 `robocopy / 7za / xcopy` 进程。

## 坑 9 · U 盘整盘掉线（一次）

- **症状**：用 WriteThrough（直写）方式做 128 MB 压测时，盘符从系统里消失，需要重新插拔。
- **后续**：`chkdsk /F` 报无问题、0 坏扇区，关键文件哈希校验全部一致（数据没坏）。
- **结论**：触发条件是"直写 + 高压力"，日常缓冲写不会复现。但说明这类盘的主控/供电不宽裕，
  想稳就换 SSD 型 U 盘。

## 坑 10 · 桌面版启动慢（原始痛点）

- **症状**：Electron 冷启动 60-85 秒（要从 U 盘读 7800 个文件 + 500 MB 的 app.asar）。
- **解决**：程序缓存到本机（首次 1-3 分钟，之后 5-15 秒）＋ 精简程序文件。
- **注意**：任何"把程序放 U 盘直接跑"的方案都绕不开这个物理限制，缓存是唯一解。

## 坑 11 · 桌面 App 的沙箱提示

- 旧版曾报"设置智能体沙盒以继续"。处理办法：配置文件里关掉 Windows 沙箱
  （`sandbox_mode` + `[windows] sandbox = "unelevated"`），并保证 `APPDATA` 被正确重定向。

## 坑 12 · Python 脚本导入了错误的同名模块

- **症状**：`AttributeError: module 'inspect' has no attribute 'cleandoc'`。
- **根因**：调试脚本放在了一个含 `inspect.py` 的目录里，Python 优先导入了它。
- **教训**：自己的调试脚本别和标准库模块同名。

## 坑 13 · PowerShell 函数名撞了内置别名

- **症状**：`Invoke-History : A positional parameter cannot be found...`
- **根因**：自定义函数取名 `R`，撞上了 PowerShell 内置别名 `r`（= `Invoke-History`）。
- **解决**：换成 `Report` 这类不会撞名的名字。
