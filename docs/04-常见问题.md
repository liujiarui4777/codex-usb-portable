# 常见问题

## 报错速查

| 现象 | 先查什么 |
|---|---|
| 双击后**窗口一闪就没** | `.ps1` 是不是 UTF-8 **with BOM**？用 `powershell -File` 手工跑一遍看报错 |
| **没有窗口但有进程** | 是否与本机已装的 Codex 冲突？确认 `APPDATA` 被重定向了 |
| 报 **SxS / 并行配置不正确** | 缓存目录是不是在 `AppData` 下？必须在用户目录（见踩坑坑 1） |
| 报 **401 / api key invalid** | 密钥分片算法两端是否一致？用 `tools/mkshards.py` 重生成一次（自带校验） |
| 报 **Unknown model** | 配置文件里的模型名要写服务商认识的名字 |
| 交互界面报 **package does not match** | 主程序是不是叫 `codex.exe` |
| 交互界面报 **no complete local package** | 无参数启动时是否漏了 `--no-daemon` |
| 启动特别慢（60-85 秒） | 是不是在从 U 盘直读？桌面版应该走本机缓存 |
| 生成的文件跑到 `C:\Users\...\Desktop` | 桌面被重定向了，让脚本用 API 动态解析真实桌面路径 |
| 报 **找不到 codex.exe / node.exe** | 组件还没放进 U 盘，跑一遍 `setup\装配.ps1` 检查 |

## 常见问题

**Q：一定要用 U 盘吗？放移动硬盘、内存卡行不行？**
A：都行。脚本只关心"有一个可写目录 + 盘符是动态的"，对设备类型没要求。

**Q：插到别人电脑上安全吗？**
A：脚本会把 `APPDATA` / `LOCALAPPDATA` 重定向到自己的缓存目录，
不会读你本机 Codex 的配置。但缓存目录会留在那台电脑上（约 2 GB），
公用的电脑建议用完就跑一次「清理本机缓存」。

**Q：换电脑要重新配置吗？**
A：不用。配置、密钥、会话历史都在 `CodexHome\\` 里，跟着 U 盘走。
每台新电脑第一次用会自动做一次程序缓存，之后就是 5-15 秒。

**Q：能不能不用密钥，直接登录官方账号？**
A：可以。在 U 盘根目录开终端执行 `codex login`，凭据存进 `CodexHome\auth.json`。
这种方式不需要分片，也不用改 `config.toml`。

**Q：U 盘拔了忘等退出怎么办？**
A：会话历史可能少最后一段。启动器会提示"等窗口提示完成再拔"，照做即可。
真丢了也不影响下次使用。

**Q：为什么桌面版第一次要等 1-3 分钟？**
A：它要把约 2 GB / 2 万个文件拷到本机（U 盘随机读天生慢）。只此一次。

**Q：能装在 Mac 上吗？**
A：本仓库只做了 Windows。Mac 上思路一样（`CODEX_HOME` 指向 U 盘 + 官方 CLI 二进制），
但脚本要重写。

**Q：浏览器界面这个入口可靠吗？**
A：脚本是完整可用的，但**没有做过充分的实测**（原作者主要用桌面版和终端版）。
它依赖 `node\` 和 `web\` 两个可选组件，缺了会明确报错。欢迎反馈问题。
