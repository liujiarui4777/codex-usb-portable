# 原理与设计

## 一、三个入口的共同骨架

三个启动器（`launch-desktop.ps1` / `launch-cli.ps1` / `launch-web.ps1`）做的事是一样的：

1. **自检**：系统是不是 64 位 Windows 10+，不是就友好提示退出。
2. **定位 U 盘**：所有路径都从脚本所在位置（`$PSScriptRoot` / `%~dp0`）推导，
   不写死盘符 —— 换到别的电脑上盘符变成 F:、G: 也能用。
3. **还原密钥**：从 `CodexHome\*.dat` 三个分片还原出 API Key，写成 `auth.json`。
4. **隔离环境**：把 `CODEX_HOME` 指向 U 盘的 `CodexHome`；桌面版还会把
   `APPDATA` / `LOCALAPPDATA` 重定向到本机缓存目录。
5. **拼 PATH**：把 U 盘上的 node / python / tools 放到 PATH 最前面。
6. **启动**：运行程序本体，等它退出。
7. **回写**：把这次产生的配置、会话历史同步回 U 盘，并**删掉明文 `auth.json`**。

## 二、为什么要把程序缓存到本机（桌面版）

Electron 桌面版有 7800 多个文件、一个几百 MB 的 `app.asar`。
直接从 U 盘读要 60-85 秒，体验很差；U 盘随机读只有十几 MB/s，这是物理限制。

所以桌面版启动器改成：

- 第一次在某台电脑上，用 `robocopy /MT:16` 把 `_internal\` 整份拷到
  `C:\Users\<用户名>\CodexPortable\<U盘ID>\`（约 2 GB，入门 U 盘 1-3 分钟）；
- 之后每次都从本机跑，**启动降到 5-15 秒**；
- 退出时把 `CodexHome` 同步回 U 盘（`/XO` 只回写更新的文件）。

代价是"在某台电脑上留下约 2 GB 缓存"，所以专门给了 `（可选）清理本机缓存.cmd`。
终端版文件少（几十个），**不需要缓存**，直接从 U 盘跑，所以是 2-3 秒。

## 三、为什么要重定向 APPDATA（坑，但必须做）

两个原因：

1. **单实例冲突**：Electron 的单实例锁是按用户数据目录判定的。如果 U 盘版和本机装的
   Codex 共用 `%APPDATA%\Codex`，后启动的那个会被"合并"掉 —— 表现为双击后一闪就没窗口。
2. **不污染宿主**：重定向之后，U 盘版写配置、写缓存都落在自己的目录里，不碰你的用户配置。

注意：**不能用 `--user-data-dir` 参数替代**（App 内部会再改 userData，导致窗口不显示），
必须改环境变量。

## 四、缓存必须避开 AppData（SxS 陷阱）

Windows 会拒绝从 `%LOCALAPPDATA%` 加载带 manifest 的 SxS 程序集，报
"应用程序的并行配置不正确"。所以缓存目录放在
`C:\Users\<用户名>\CodexPortable\` 而不是 `AppData` 下。
同样的文件放 `E:\` 或 `D:\` 都能跑，放 `AppData` 就激活失败。

## 五、密钥分片机制

- 生成：把 Key 按 UTF-8 字节切成 3 段（每段 `ceil(总长/3)`），
  每段各自与掩码 `codex-portable-2026` 循环 XOR（都从下标 0 开始），再各自 Base64，
  存成 `user-settings.dat` / `window-layout.dat` / `cache-index.dat`。
- 还原：启动器逐段 Base64 解码 → XOR → 拼接 → 写 `auth.json`。
- 注意：**生成端和还原端的切分方式必须完全一致**，否则解出错误字节，表现为 401
  （这个坑我们踩过：早期版本一边"整体 Base64 后切段"、一边"逐段解码"）。

文件名的选择是刻意的：看起来像普通设置文件，避免"随手翻 U 盘看到一串 sk- 开头的字符"。

## 六、配置文件要点

- 模型名要写服务商认识的名字（写错会被当成"未知模型"直接报错）。
- 走第三方兼容接口时用 `requires_openai_auth = true` + `auth.json` 里的 Key，
  **不要用 `env_key`**（实测会 401）。
- 便携场景可以关掉 Windows 沙箱（目标机器通常没有 Codex 的沙箱服务）：
  `[windows] sandbox = "unelevated"`、`experimental_windows_sandbox = false`。
