# 装配指南

目标：把程序组件按下面的位置放进 U 盘，让启动器能直接跑起来。
**本仓库不提供这些二进制**，请从各自上游下载（体积大 + 许可证原因）。

## 一、最终目录结构

    E:\
    ├─ _internal\app\ChatGPT.exe        ← 桌面版程序（可选，但要用桌面入口就必须有）
    ├─ codex\codex.exe                  ← Codex 命令行版（必需，至少要有这个）
    ├─ web\start-web.mjs                ← 浏览器界面（可选）
    ├─ node\node.exe                    ← 便携 Node（用浏览器界面时需要）
    ├─ python\python\python.exe         ← 便携 Python（做 Excel/PPT/PDF 时需要）
    ├─ tools\                           ← pandoc / ffmpeg / poppler / git / 7zip / uv / jq（可选）
    └─ CodexHome\config.toml            ← 配置（模板已在仓库里）

## 二、组件对照表

| 组件 | 从哪拿 | 解压后放到 | 备注 |
|---|---|---|---|
| **Codex 命令行版** | [openai/codex releases](https://github.com/openai/codex/releases) → `codex-x86_64-pc-windows-msvc.exe.zip` | `codex\codex.exe` | **必须重命名为 `codex.exe`**，否则交互界面报 “package does not match this platform” |
| **桌面版程序** | [lusipad/unofficial-codex-app-offline](https://github.com/lusipad/unofficial-codex-app-offline/releases) → `portable.zip` | `_internal\` | 解压后找到含 `app\ChatGPT.exe` 的那层目录，整体改名为 `_internal` |
| **浏览器界面** | 同上仓库 → `web.zip` | `web\` | 解压后去掉顶层目录，内容直接放进去 |
| **便携 Node** | [nodejs.org/dist](https://nodejs.org/dist/latest/win-x64/) → `node.zip` | `node\` | 解压后去掉顶层目录（Node 18+ 即可） |
| **便携 Python** | [python.org](https://www.python.org/downloads/windows/) → Windows embeddable package (64-bit) | `python\python\` | + 装下面那批库 |
| **工具链** | pandoc / ffmpeg / poppler / Git(PortableGit) / 7-Zip / uv / jq 各自官网 | `tools\` 下同名子目录 | 启动器会自动把它们加进 PATH |

> 也可以让仓库里的装配助手代劳，它会自动下载、解压、摆放上面这些组件：
>
>     cd setup
>     powershell -ExecutionPolicy Bypass -File setup.ps1
>     powershell -ExecutionPolicy Bypass -File setup.ps1 -WithPython -WithTools
>
> 或者直接在 U 盘上双击 `一键装配.cmd`。

## 三、Python 与常用库（做表格/文档/PDF 用）

解压 embeddable 包到 `python\python\` 之后，装这些库（写在 U 盘上，不污染宿主）：

    # 方式一：用 U 盘自带的 uv（tools\uv\uv.exe），最快
    uv pip install --python E:\python\python\python.exe openpyxl pandas python-docx python-pptx \
        reportlab pdfplumber pypdfium2 Pillow lxml requests beautifulsoup4 numpy

    # 方式二：直接用 python -m pip（需要先执行 get-pip.py）
    E:\python\python\python.exe -m pip install openpyxl pandas python-docx python-pptx reportlab

装完确认一下：

    E:\python\python\python.exe -c "import openpyxl, docx, pptx, reportlab, pdfplumber; print('ok')"

## 四、想省空间？可以精简

原版桌面包解压后有 2 GB 左右、两万多个文件，按需删掉这些不影响使用：

- `_internal\` 里 Mac / Linux 版本的二进制、`*.pdb` 调试符号
- 用不到的语言包（`locales\` 里只留 `zh-CN` / `en-US`）
- 保留其余运行必需文件（尤其别删 `app.asar`、`chrome.dll` 之类）

精简完第一次启动会重新做本机缓存，属正常。

## 五、文件系统选择

- **用 exFAT**：无目录项数量限制、跨平台可读写、顺序写速度最好。
- 不要用 FAT32：单个目录最多约 1.6 万个长文件名项，程序包会直接写不进去。
- NTFS 在部分入门 U 盘上反而更慢（日志开销），如需 >4 GB 单文件再考虑。
