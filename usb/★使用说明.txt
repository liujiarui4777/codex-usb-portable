★ Codex 便携版 使用说明
================================================

【怎么用】
  插上 U 盘 → 打开 U 盘 → 双击：

  ▶ 【Windows】启动 Codex(桌面版)      ← 官方桌面界面，和你电脑上装的 Codex 一样
  ▶ 【Windows】启动 Codex(终端)        ← 秒开，键盘操作
  ▶ 【Windows】启动 Codex(浏览器界面)   ← 浏览器里用完整界面（需 web\ 与 node\）
  ▶ （可选）检查这台电脑能否运行.cmd    ← 插到新电脑先跑一次，自动体检
  ▶ （可选）收集本机环境档案.cmd        ← 采集本机信息写回 U 盘（约 30 秒）
  ▶ （可选）清理本机缓存.cmd            ← 清理留在本机上的程序缓存

  首次在某台电脑上打开，Windows 可能提示"未知发布者"，选"仍要运行"。

【第一次使用】
  1. 确认程序组件已就位（_internal\ 、codex\ 等）：
     如果双击后报"程序不存在"，说明组件还没放进来，见随包的装配说明。
  2. 配好 API 密钥：双击 CodexHome\设置API密钥.cmd
     （也可以改用官方账号登录：在 U 盘根目录打开终端执行  codex login）

【启动速度（实测参考）】
  桌面版：某台电脑第一次约 1-3 分钟（把程序缓存到本机，只做一次），之后 5-15 秒
  终端版：约 2-3 秒
  浏览器版：约 3-5 秒

  缓存位置：C:\Users\<你的用户名>\CodexPortable\
  注意：缓存必须避开 AppData 目录，否则 Windows 会拒绝加载（脚本已规避）。

【对电脑的要求】
  仅需 64 位 Windows 10 / 11，无需安装任何运行库（程序只用系统 DLL）。
  与本机已安装的 Codex 互不干扰（使用独立的用户数据目录）。

【密钥是怎么存的】
  API 密钥不以明文保存：拆成 3 个分片，各自混淆后 Base64 存放在 CodexHome\*.dat；
  启动时在内存里还原，只在使用期间短暂写入 auth.json，退出即删除。
  注意：这是"避免明文裸奔"的混淆，不是加密——能拿到 U 盘的人仍可能还原出密钥。
  更稳妥的做法：只放低额度/可随时吊销的密钥，或给整个 U 盘开 BitLocker。

【注意事项】
  1. 退出 Codex 后，等启动器窗口提示完成，再拔 U 盘（保证配置与会话写回 U 盘）。
  2. 入门级 U 盘写零散小文件很慢，不要往这个盘里拷几千个小文件。
  3. 想在本机重新建立缓存，双击「（可选）清理本机缓存.cmd」。

【换电脑】
  配置、密钥、技能、会话历史都跟着 U 盘走；每台电脑第一次用会自动做本机缓存。

【更新程序】
  用新版离线包替换 _internal\（或 codex\）目录后，第一次启动会自动重新缓存。
